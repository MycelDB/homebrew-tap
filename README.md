# MycelDB Homebrew Tap

Homebrew tap for MycelDB packages.

## Mycel Console

Install the macOS desktop console with:

```sh
brew install --cask myceldb/tap/mycel-console
```

Upgrade with:

```sh
brew update
brew upgrade --cask mycel-console
```

Mycel Console release assets are published from `MycelDB/mycel-console` GitHub Releases.
